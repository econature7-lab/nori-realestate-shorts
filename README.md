# 노리 · 부동산쇼츠생성기 **v3**

사진 5~8장이면 **소리까지 들어간** 9:16 부동산 쇼츠가 완성되는 **단일 HTML 웹앱**입니다.
슈퍼쇼츠(supershorts.co.kr)를 참고하되, 부동산 매물에 맞춰 더 화려하게 재구성했습니다.

- 라이브: <https://econature7-lab.github.io/nori-realestate-shorts/>
- 파일 하나(`index.html`)로 동작합니다. 빌드·CDN·외부 라이브러리 없음, 인터넷 없이 `file://`로도 100% 동작.
- **v2 핵심: 저장되는 영상에 배경음악·전환 효과음·내레이션이 실제로 함께 녹음됩니다(무음 아님).**
- **v3 핵심: 액티브 모션(스프링 등장·상단 진행 바·스냅 줌·화이트 플래시 컷·자막 키워드 하이라이트) + 빠른 템포(장면 2초 기본, BGM 126 BPM) + 성우 음성 실전 테스트 완료.**

## v3에서 새로 들어간 것

### 1. 액티브 모션 (Canvas 30fps 실시간)
- **탄력 등장**: 장면 시작 0~0.45초에 훅 타이틀(위→아래), 가격 스티커·급매 배지(0→1.12→1.0 팝), 스펙 뱃지가 순차적으로 팡 튀어나옵니다(`easeOutBack` 스프링 + 스태거).
- **상단 세그먼트 진행 바**: 인트로+장면 개수만큼 나뉜 막대가 실시간으로 차오릅니다(릴스·쇼츠 스타일).
- **끌어당기는 카메라**: Ken Burns 폭을 1.0→1.20 이상으로 키우고, 장면 초반 0.28초 **풀인 줌** + 컷 직전 **0.15초 스냅 줌(whip)** 을 더했습니다. 모션 8종(자동·빠른 줌인·줌아웃·좌우 패닝·줌+패닝·펀치 줌·흔들림 줌).
- **컷 전환**: **스냅 컷**(앞 장면이 빨려가며 다음 장면이 튀어나옴) + 모든 장면 전환에 **0.15초 화이트 플래시** + 슬라이드는 와이프 방식.
- **자막 하이라이트**: 자막이 단어별로 탄력 있게 올라오고, 가격·숫자·핵심 키워드 하나에 형광 마커가 스윽 그어집니다(템플릿별 색).
- **BGM 126 BPM**: 4분의 4 킥·2/4박 클랩·16분 하이햇·8분 베이스·엇박 스타브로 텐션을 올렸습니다(자체 합성, 외부 음원 0개).

### 2. 빠른 템포 기본값 (다작용)
- 기본 **장면 2초**(선택 1.5~5초), **인트로 1.8초** → 사진 5장이면 **12초 안팎**.
- AI TTS **말 속도 1.12~1.2배** 선택(기본 1.12) — PCM 리샘플로 빠릿한 쇼츠 톤.
- 내레이션 문장도 2초 장면에 맞게 짧게 생성합니다.

### 3. 무료 키로 하루 10편 — TTS 호출 1회 모드
- **전체 대본 1회 호출 → 무음 구간으로 장면별 분할**(기본). Gemini 무료 한도(분당 3회·하루 10회)에서도 한 편을 1회로 제작.
- 장면별 호출 모드도 남겨 둠(장면 경계 정확).
- 음성이 길면 **장면 길이를 음성에 맞춰 자동 조정**(1.5~5초).

### 4. 다작 편의
- TTS API 키를 **서비스별로 localStorage에 저장** → 다음 매물·다음 방문에 다시 입력하지 않음(공개 저장소 코드에는 키를 넣지 않음).
- 템플릿·BGM·템포·모션·전환·속도 설정도 저장(사진·입력칸은 기존 원칙대로 새로고침 시 비움).
- **후킹 카피 변주 풀 8종 + CTA 4종**: 대본을 새로 만들 때마다 다음 패턴으로 순환해 첫 줄이 겹치지 않습니다.
- **샘플 체험 프리셋 4종 순환**: 성산시영 아파트(마포) → 강변역 테크노마트 사무실(보증금 2,000/월 140, 광진) → 홍대입구 1층 상가(보증금 5,000/월 350) → 자양동 한강뷰 아파트(전세 6.3억). 버튼을 누를 때마다 다음 매물 예시로 바뀝니다.
- **`#gkey=` 링크로 키 자동 저장**: `…/?v=20261126v3#gkey=<키>` 를 열면 Gemini 키를 이 브라우저에 저장하고 해시를 즉시 지웁니다(소스에 키 없음).

## 3단계 사용법

1. **사진** — 매물 사진 5~8장을 고르면 장면이 자동으로 만들어집니다. 사진마다 **방 이름(외관·거실·주방·안방·작은방·창가/뷰·욕실·테라스·상권/주변·직접입력)** 을 골라 사진과 자막이 어긋나지 않게 합니다. 파일 이름에 exterior/living·거실/주방/욕실 같은 단서가 있으면 자동으로 잡아 줍니다.
2. **정보·대본** — 매물 유형·거래 유형·가격·면적·역·입주일을 적으면 대본 스타일 3종(요약형·후킹형·상세형)으로 장면별 대본이 자동으로 채워집니다.
3. **재생·저장** — 9:16 캔버스로 확인한 뒤 **소리가 들어간 영상**으로 저장합니다. (가능한 브라우저는 MP4, 그 외 WebM)

## v2에서 새로 들어간 것

### 1. 사운드 (전부 앱이 직접 합성 · 외부 음원 파일 0개)
- **자체 BGM 4종**: ① 경쾌한 쇼츠 비트 ② 세련된 라운지 ③ 어쿠스틱 기타풍 ④ 차분한 피아노 — Web Audio API로 실시간 합성하며, `OfflineAudioContext`로 영상 길이에 맞춰 렌더링한 뒤 녹화 스트림에 합칩니다.
- **장면 전환 효과음**: 슬라이드=휙, 줌=라이저, 페이드=톡 + 장면마다 낮은 킥. 크기 조절 가능.
- **내레이션 3가지**:
  - **마이크 녹음** — 영상이 무음으로 재생되면 대본을 읽으면, 녹음이 끝나고 자동으로 **BGM 덕킹**(음악이 줄어들며 목소리가 섞임)
  - **음성 파일(MP3·M4A·WAV)** — 1개면 처음부터, 장면 수만큼 넣으면 장면 순서대로 배치
  - **AI TTS** — OpenAI TTS / ElevenLabs / Google Gemini TTS 키를 넣으면 장면별 대본을 실제 음성으로 만들어 믹싱 (키는 이 브라우저에만 저장)
- 저장 후에는 녹음 파일의 음량을 자동 확인해 **“🔊 소리 확인 -12dB”** 처럼 표시합니다.

### 2. 움직임·전환·템플릿 8종
- **Ken Burns 모션**: 장면마다 줌인 / 줌아웃 / 좌우 패닝 (자동 배분 또는 직접 선택)
- **장면 전환 4종**: 슬라이드 · 줌인 전환 · 페이드 · 믹스(자동 섞기)
- **템플릿 8종** (레이아웃·배지·말풍선·타이틀 구조가 서로 다름):
  1. 슈퍼훅 네이비 — 상단 대형 2줄 타이틀(노랑·흰색) + 사진 위 급매/핵심 라벨 + 굵은 박스 자막 + 하단 배너
  2. 핫딜 급매 빨강 — 상단 특가 배너 + 원형 가격 스티커 + 스펙 3뱃지
  3. 강남·한강 딥포레스트 — 다크그린 + 골드 라인 + 여백
  4. 화이트 매거진 — 밝은 에디토리얼 + 둥근 카드 + 스펙표
  5. 풀스크린 릴스 — 꽉 찬 사진 + 상단 그라데이션 훅 + 하단 대형 자막
  6. 2분할 비교형 — 상단 메인 사진 + 하단 포인트 강조
  7. 상가·사무실 프로 — 수익률·보증금·월세·전용면적 강조 배지
  8. 테라코타 감성 — 따뜻한 브이로그풍 + 말풍선 자막

### 3. 사용성·정확성 수정
- **중개사무소명·채널명·연락처·대표자·등록번호 자동 저장** — 새로고침해도 유지, 기본값 `010-0000-0000`은 사라졌고 비어 있으면 경고 표시
- **사진마다 방 이름 선택** — 사진 순서와 자막이 어긋나는 문제 해결
- **한국어 단어 단위 줄바꿈** — “남 / 향”처럼 한 글자만 떨어지는 문제 해결, 긴 제목은 자동 축소
- **장면별 표시 시간 2~5초** + 장면 기본 길이·인트로 길이 선택
- 사진 업로드 순서 보존(비동기 로딩 순서 뒤바뀜 수정)

### 4. 저작권·표시광고 안전
- 음악·효과음은 **100% 코드로 합성**, 외부 음원·폰트·이미지를 불러오지 않습니다. 폰트는 시스템 폰트 스택만 사용합니다.
- 후킹 대본의 **“사진은 실제 매물입니다”** 문구는 기본에서 뺐습니다(허위매물·표시광고법 오해 방지). 실제 매물일 때만 직접 넣으세요.
- 지도는 키를 넣었을 때만 카카오 SDK를 불러옵니다. 넣지 않으면 내장 약도로 동작합니다.

## 저장 방식

- 매물 정보·사진은 저장하지 않습니다(새로고침 시 초기화). **사무소 정보·디자인 설정·사운드 설정만** `localStorage`에 저장합니다.
- 사진·음성·영상은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다. TTS를 쓸 때만 입력한 대본이 해당 AI 서비스로 전송됩니다.

## 검증(v2)

- 헤드리스 Chromium에서 사진 5장 업로드 → 정보 입력 → 녹화·저장까지 실제 수행, 저장 파일에 **Opus 오디오 스트림 포함** 확인.
- 오디오 마스터 렌더 피크 0.72(무음 아님), 마이크 녹음 믹싱 시 0.95 확인.
- 템플릿 8종·전환 3종·인트로 줄바꿈·사무소 정보 유지·사진 순서/라벨을 화면 캡처로 확인.
