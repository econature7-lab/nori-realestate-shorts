# 노리 · 부동산쇼츠생성기

사진 5~8장이면 9:16 부동산 쇼츠가 완성되는 **단일 HTML 웹앱**입니다.
슈퍼쇼츠(supershorts.co.kr)의 3가지 대본 스타일·5종 템플릿·인트로보드·AI 목소리 프리셋을
부동산 매물에 맞게 재구성했습니다.

- 라이브: <https://econature7-lab.github.io/nori-realestate-shorts/>
- 파일 하나(`index.html`)로 동작합니다. 빌드·CDN·외부 라이브러리 없음, 인터넷 없이 `file://`로도 100% 동작.

## 3단계 사용법

1. **사진** — 매물 사진 5~8장을 고르면 장면이 자동으로 만들어집니다. (샘플 6장으로 바로 체험 가능)
2. **정보·대본** — 매물 유형(원룸·오피스텔 / 아파트·빌라 / 상가·사무실)과 거래 유형(매매/전세/월세)을 고르고
   가격·면적·역·입주일을 적으면, 대본 스타일 3종(요약형·후킹형·상세형)에 맞춰 장면별 대본이 자동으로 채워집니다.
3. **재생·저장** — 9:16 캔버스로 재생해 확인하고 WebM 영상으로 저장합니다. (PNG 프레임 저장, 대본 복사도 지원)

## 주요 기능

- **디자인 템플릿 5종**: 풀레이아웃 / 정보성 네이비 / 정보성 다크 / 카드형 / 바이럴 슬레이트 + 인트로보드(제목·강조색)
- **AI 목소리 11종 + 속도 3단**: 브라우저 내장 한국어 음성으로 미리듣기
- **부동산 특화**: 가격·면적·역세권·입주일 스펙 배지, 중개사무소·채널·연락처 워터마크, 마지막 장면 문의 유도
- **장면 편집**: 장면별 소제목·보조 문구·대본·자막 위치(상단/기본/하단)·표시 시간
- **지도·공공데이터**: 카카오/네이버 지도 키가 없어도 내장 약도로 동작. 실거래가·상권·기상청 단기예보·서울 열린데이터 예시 내장(키 입력 시 실데이터 연동 시도)
- **날짜·검색**: KST 기준 월간 달력, 날짜별 일정 모아보기, 이름·날짜 검색과 유형/상태 필터
- **알림·설정**: 오늘 할 일 리마인더, 시간 알림(브라우저 알림), API 키 저장, 예시 데이터 1회성 관리

## 저장 방식

- 쇼츠 편집 내용(사진·대본)은 **저장하지 않습니다.** 새로고침하면 초기화됩니다.
- `localStorage`에는 방문자 구분 키, API 키, 일정·할 일, 예시 데이터 삽입 여부만 저장합니다.
- 사진과 영상은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.
