# 노리 · 부동산쇼츠생성기 **v4 (슈퍼쇼츠 정통 스타일)**

사진 5~8장이면 **소리까지 들어간** 9:16 부동산 쇼츠가 완성되는 **단일 HTML 웹앱**입니다.
v4는 실제 **슈퍼쇼츠 채널 화면과 1:1로 맞춘 정통 레이아웃**으로 다시 그렸습니다.

- 라이브: <https://econature7-lab.github.io/nori-realestate-shorts/>
- 파일 하나(`index.html`)로 동작합니다. 빌드·CDN·외부 라이브러리 없음, 인터넷 없이 `file://`로도 100% 동작.
- 지도 탭만 예외로 **OpenStreetMap 타일 이미지**를 불러옵니다(키 불필요). 인터넷이 없으면 내장 약도로 자동 대체됩니다.

## v4에서 달라진 것 (사용자 피드백 "슈퍼쇼츠 같은 느낌이 없어" 반영)

### 1. 어두운 스크림(그라데이션 덮개) 완전 제거
- v3는 1080×1920 사진 위에 검정 그라데이션을 덮어 매물이 칙칙하고 어둡게 보였습니다.
- v4는 **사진을 원색 그대로** 보여 줍니다. 밝기·채도만 아주 살짝(1.05/1.14) 끌어올린 보정본을 한 번 만들어 캐시합니다.
- 상단 헤더·자막·배너는 모두 **솔리드 판**으로 분리해서, 글씨는 또렷하고 사진은 밝게 유지됩니다.

### 2. 슈퍼쇼츠 정통 3단 프레임 → 1번 기본 템플릿 `슈퍼쇼츠 오리지널`
| 구역 | 위치 | 내용 |
|---|---|---|
| 상단 헤더 | y 0~392 | 솔리드 네이비(#16204E) · 거래/유형/동네 킥커(27px) · **매물명 흰색 76px** · **가격 형광노랑(#FFE033) 100px** |
| 진행 바 | 맨 위 8px | 얇은 세그먼트 바 (사진을 가리지 않음) |
| 중앙 사진 | y 414~1344 | 밝고 쨍한 사진(1000×930, 라운드 22) · 빠른 줌/패닝 · 스냅 컷 |
| 포인트 배지 | 사진 모서리 | `급매` `3층` `주차가능` `즉시 입주` 등 1개 |
| 중앙 하단 자막 | y 1364~1652 | 굵은 둥근 박스(솔리드 네이비) · **60px 흰 글씨, 핵심어 노란 마커**, 최대 2줄 + 보조 1줄 |
| 하단 고정 배너 | y 1672~1920 | 중개사무소명 · **전화번호 58px** · 대표/등록번호 |

- 자막이 헤더 가격을 그대로 반복하면, 정보가 더 많은 보조 문장을 자막으로 올려 중복을 없앴습니다.
- **인트로(0번 프레임 = 썸네일)** 도 같은 3단 구성입니다. 거대한 2줄 타이틀 + 밝은 1번 사진 + `급매`(빨강)·`즉시 입주`(노랑) 배지 + 핵심 포인트 자막 + 중개소 바.

### 3. 나머지 8종 템플릿도 같은 기준으로 정돈
- **슈퍼훅 네이비**: 왼쪽 정렬 헤더 + 풀블리드 사진 + 노란 포인트 라인 (스크림 없음)
- **핫딜 급매 빨강**: 솔리드 레드 헤더 + 급매 스탬프 (사진 어둡게 덮던 오버레이 제거)
- **풀스크린 릴스**: 꽉 찬 밝은 사진 + 솔리드 타이틀 바(검정 그라데이션 제거) + 자막 박스
- **2분할 비교형 / 상가·사무실 프로**: 사진 위 그라데이션 덮개·격자 오버레이 제거, 라벨은 어두운 알약 위로
- **강남·한강 딥포레스트 / 화이트 매거진 / 테라코타 감성**: 기존 톤 유지 + 타이틀 크기·가독성 보정

### 4. 지도: **키 없이 실제 지도(OpenStreetMap)**
- `[지도·공공데이터]` 탭에서 카카오 키가 없어도 **OSM 타일 실제 지도**가 바로 뜹니다.
  - 캔버스에 타일을 직접 그립니다(외부 라이브러리 0). **확대(+)/축소(−)/전체 보기/드래그/휠 줌/더블클릭 줌** 지원.
  - 핀: **역삼역 · 강변역 테크노마트 · 홍대입구 · 자양동 · 합정역** (실제 위경도). 핀 클릭 → 오른쪽 매물 정보 패널·목록 연동.
  - `© OpenStreetMap contributors` 표기, `실제 지도 / 약도` 토글로 내장 약도와 전환.
  - 오프라인이거나 타일이 막히면 "내장 약도로 보기" 안내가 뜨고 기존 약도로 계속 동작합니다.
- 카카오 키를 넣으면 지금처럼 카카오맵으로 전환됩니다(키가 있을 때만).

### 5. 구버전 예시 데이터 자동 정리 (localStorage)
- 예전 버전을 열었던 브라우저에 남아 있는 **구버전 기본 예시(옛 지역명)** 를 앱이 시작할 때 자동으로 찾아 **새 예시(역삼동 오피스텔 등)** 로 바꿉니다.
- **중개사무소명·채널명·연락처·대표/등록번호·API 키는 절대 건드리지 않습니다**(설정·키 항목은 검사 대상에서 제외).
- 정리한 항목은 `data-nori-legacy-purge` 속성과 토스트("예전 예시 데이터 N개를 새 예시로 정리했습니다")로 확인할 수 있습니다.

## 그대로 유지되는 것 (v3 기능)
- 액티브 모션: 스프링 등장 · 스냅 줌 컷 · 화이트 플래시 · 자막 단어별 등장/형광 마커
- 빠른 템포: 장면 기본 2초 · 인트로 1.8초 · BGM 126BPM · TTS 1.12배
- 사운드: 자체 합성 BGM 4종·전환 효과음·내레이션(마이크/음성파일/AI TTS)·덕킹
- Gemini TTS 1회 호출 → 장면 분할(무료 하루 10편), 키는 브라우저에만 저장
- `#gkey=<키>` 링크로 키 자동 저장(해시 즉시 제거, 소스에 키 없음)
- 사진별 방 이름 지정, 한국어 단어 단위 줄바꿈, 샘플 체험 프리셋 순환

## 3단계 사용법
1. **사진** — 매물 사진 5~8장 선택(파일 이름에서 거실/주방/욕실 등 자동 인식, 직접 수정 가능)
2. **정보·대본** — 유형·거래·가격·면적·역·입주일 입력 → 대본 스타일 3종으로 장면별 자동 작성
3. **재생·저장** — 9:16 캔버스 확인 → **⬇ 영상 저장**(음악·효과음·내레이션 함께 녹음, MP4 또는 WebM)

## 저장 방식
- 매물 정보·사진은 저장하지 않습니다(새로고침 시 초기화). **사무소 정보·디자인 설정·사운드 설정·API 키만** `localStorage`.
- 사진·음성·영상은 브라우저 안에서만 처리됩니다. TTS를 쓸 때만 대본이 해당 AI 서비스로 전송됩니다.
- 외부 요청은 **지도 탭의 OSM 타일 이미지**와 (키를 넣었을 때) 카카오 SDK뿐입니다.
