이 음악과 효과음이 영상 파일에 그대로 녹음됩니다. 외부 음원 파일을 쓰지 않습니다.
내레이션 (선택 · 없으면 음악만)

음악만 들어간 쇼츠를 만듭니다. 목소리를 넣으려면 마이크 녹음 또는 음성 파일을 쓰세요.

「녹음 시작」을 누르면 영상이 소리 없이 처음부터 재생됩니다. 장면이 넘어갈 때 대본을 읽어 주세요. 녹음이 끝나면 자동으로 음악이 줄어들며(덕킹) 영상에 섞입니다.

처음 한 번 브라우저가 마이크 사용을 물어봅니다. 허용해 주세요.

MP3 · M4A · WAV 파일을 넣으세요. 1개면 처음부터 끝까지, 장면 수만큼 넣으면 장면 순서대로 배치됩니다.

음성 파일은 기기 안에서만 처리되고 서버로 올라가지 않습니다.

본인 API 키를 넣으면 장면 대본을 실제 음성으로 만들어 영상에 직접 섞습니다. 키는 이 브라우저에만 저장되고 외부로 보내지 않습니다(해당 AI 서비스 호출에만 사용).

OpenAI는 브라우저에서 직접 호출하는 것을 막아 두었습니다(CORS). OpenAI 키만 있다면 마이크 녹음이나 음성 파일을 쓰고, TTS를 쓰려면 Gemini 또는 ElevenLabs 키를 넣어 주세요.

무료 Gemini 키는 분당 3회·하루 10회 한도가 있어요. 한 편을 1회 호출로 만들면 하루 10편까지 가능합니다.

키가 없으면 마이크 녹음이나 음성 파일을 쓰세요.
브라우저 미리듣기(🔊 목소리 미리듣기)는 소리만 들려주는 기능이라 영상에는 안 들어갑니다. 영상에 목소리를 넣으려면 위 3가지 중 하나를 쓰세요.
